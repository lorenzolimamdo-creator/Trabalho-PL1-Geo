# Portal da Turma 117

Portal desenvolvido como projeto final da disciplina **Prática de Laboratório 1 (PL1)**, no **IFSP — Campus Cubatão**, pela **Turma 117**, em 2026.

## Sobre o projeto

O portal reúne as pesquisas de Geografia produzidas pela turma sobre os impactos da computação no meio ambiente.

O site apresenta as pesquisas organizadas por tema e autoria, com ferramentas de busca, filtros e uma atividade interativa.

## Equipe

Os integrantes da Equipe do Portal, seus papéis e os grupos produtores que representam estão identificados na página [Equipe](equipe.html).

## Tecnologias

- HTML
- CSS
- JavaScript

## Fontes e créditos

As fontes consultadas para as pesquisas estão indicadas nas respectivas páginas dos trabalhos. Os créditos de imagens, vídeos e demais materiais de terceiros devem ser consultados junto aos conteúdos em que são utilizados.# Trabalho-geografia-Nelson
