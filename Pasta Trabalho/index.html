Data centers e seus impactos ambientais

Como a expansão da infraestrutura digital pode afetar o meio ambiente? Este projeto investiga os impactos ambientais dos data centers, com atenção especial à expansão desse setor na região de Campinas, em São Paulo.

Um trabalho interdisciplinar desenvolvido no contexto das disciplinas de Prática de Laboratório 1 e Geografia.

Explorar as pesquisas

Por que estudar os data centers?

Os data centers são estruturas responsáveis por armazenar, processar e distribuir os dados utilizados em serviços digitais. Com o crescimento da internet e da inteligência artificial, a demanda por essas instalações também aumenta.

Apesar de sua importância para a sociedade e para o desenvolvimento tecnológico, essas estruturas exigem grandes quantidades de energia, sistemas de refrigeração e extensas áreas para sua implantação. Por isso, sua expansão levanta questões sobre o uso dos recursos naturais, a ocupação do território e a preservação ambiental.

A região de Campinas tornou-se um exemplo relevante desse processo, especialmente diante dos novos empreendimentos previstos para Barão Geraldo.

O projeto integra conhecimentos das duas disciplinas, relacionando a produção de conteúdo geográfico ao desenvolvimento de uma aplicação web.

A disciplina e o desenvolvimento do portal

A Prática de Laboratório 1 propõe a aplicação dos conhecimentos de programação na construção de soluções digitais. Neste projeto, utilizamos HTML para estruturar as páginas, CSS para definir a identidade visual e JavaScript para organizar os conteúdos e implementar funcionalidades interativas.

O resultado é este portal, desenvolvido para reunir e apresentar as produções da turma de forma organizada, acessível e adaptável a diferentes dispositivos.

Para conhecer a documentação das tecnologias utilizadas, consulte a documentação da MDN Web Docs .
